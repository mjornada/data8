Unindo Tabelas por Colunas

Até agora, vimos como trabalhar com dados contidos em uma única tabela. No entanto, em muitas situações, os dados que precisamos analisar estão distribuídos em várias tabelas diferentes. Nesta seção, aprenderemos como unir tabelas por colunas, combinando informações de diferentes fontes.

O Método join

O método join permite combinar duas tabelas com base em colunas que contêm valores correspondentes. Vamos começar com um exemplo simples para entender como funciona.

Suponha que temos duas tabelas: uma contendo informações sobre estudantes e outra contendo suas notas em um exame.

estudantes = Table().with_columns(
    'ID', make_array(1, 2, 3, 4, 5),
    'Nome', make_array('Ana', 'Bruno', 'Carlos', 'Diana', 'Eduardo')
)
estudantes
Out[1]:
ID Nome
1 Ana
2 Bruno
3 Carlos
4 Diana
5 Eduardo 
notas = Table().with_columns(
    'ID', make_array(1, 2, 4, 5, 6),
    'Nota', make_array(85, 92, 78, 95, 88)
)
notas
Out[2]:
ID Nota
1 85
2 92
4 78
5 95
6 88

Observe que ambas as tabelas têm uma coluna chamada 'ID', que contém identificadores únicos para cada estudante. No entanto, as tabelas não contêm exatamente os mesmos IDs: o estudante com ID 3 (Carlos) está na tabela de estudantes, mas não tem nota registrada, e há uma nota para o ID 6, que não corresponde a nenhum estudante na primeira tabela.

Para combinar essas tabelas com base na coluna 'ID', usamos o método join:

estudantes.join('ID', notas)
Out[3]:
ID Nome Nota
1 Ana 85
2 Bruno 92
4 Diana 78
5 Eduardo 95

O resultado é uma nova tabela que contém apenas as linhas onde o valor da coluna 'ID' aparece em ambas as tabelas originais. Observe que Carlos (ID 3) e a nota do ID 6 não aparecem no resultado, pois esses IDs não estão presentes em ambas as tabelas.

Tipos de Junções

A operação que acabamos de realizar é chamada de junção interna (inner join), que retorna apenas as linhas com valores correspondentes em ambas as tabelas. No entanto, às vezes queremos manter todas as linhas de uma das tabelas, mesmo que não haja correspondência na outra tabela.

Para isso, podemos usar o parâmetro keep do método join:

# Manter todas as linhas da tabela de estudantes
estudantes.join('ID', notas, keep=True)
Out[4]:
ID Nome Nota
1 Ana 85
2 Bruno 92
3 Carlos nan
4 Diana 78
5 Eduardo 95

Agora, Carlos aparece no resultado, mas com um valor nan (not a number) na coluna 'Nota', indicando que não há nota correspondente para ele.

Se quisermos manter todas as linhas da segunda tabela, podemos inverter a ordem das tabelas:

# Manter todas as linhas da tabela de notas
notas.join('ID', estudantes, keep=True)
Out[5]:
ID Nota Nome
1 85 Ana
2 92 Bruno
4 78 Diana
5 95 Eduardo
6 88 nan

Agora, a nota do ID 6 aparece no resultado, mas com um valor nan na coluna 'Nome', indicando que não há estudante correspondente para esse ID.

Junção com Colunas de Nomes Diferentes

Em alguns casos, as colunas que queremos usar para unir as tabelas podem ter nomes diferentes. Vamos ver um exemplo:

cursos = Table().with_columns(
    'Estudante_ID', make_array(1, 2, 3, 4, 5),
    'Curso', make_array('Matemática', 'Física', 'Química', 'Biologia', 'História')
)
cursos
Out[6]:
Estudante_ID Curso
1 Matemática
2 Física
3 Química
4 Biologia
5 História

Neste caso, a tabela cursos usa 'Estudante_ID' como identificador, enquanto a tabela estudantes usa 'ID'. Para unir essas tabelas, precisamos especificar ambos os nomes de colunas:

estudantes.join('ID', cursos, 'Estudante_ID')
Out[7]:
ID Nome Curso
1 Ana Matemática
2 Bruno Física
3 Carlos Química
4 Diana Biologia
5 Eduardo História

Combinando Múltiplas Tabelas

Podemos combinar mais de duas tabelas realizando junções sequenciais. Vamos combinar as três tabelas que criamos:

# Primeiro, unimos estudantes e cursos
estudantes_cursos = estudantes.join('ID', cursos, 'Estudante_ID')

# Em seguida, unimos o resultado com a tabela de notas
estudantes_cursos.join('ID', notas)
Out[8]:
ID Nome Curso Nota
1 Ana Matemática 85
2 Bruno Física 92
4 Diana Biologia 78
5 Eduardo História 95

Observe que Carlos (ID 3) não aparece no resultado final porque ele não tem uma nota correspondente na tabela notas.

Exemplo: Dados de Censo

Vamos ver um exemplo mais realista usando dados de censo. Suponha que temos duas tabelas: uma contendo informações demográficas e outra contendo informações sobre renda.

# Tabela com informações demográficas
demograficos = Table().with_columns(
    'ID', make_array(1, 2, 3, 4, 5),
    'Idade', make_array(25, 32, 45, 28, 36),
    'Gênero', make_array('F', 'M', 'F', 'M', 'F')
)

# Tabela com informações de renda
renda = Table().with_columns(
    'Pessoa_ID', make_array(1, 2, 4, 5, 6),
    'Renda_Anual', make_array(45000, 62000, 55000, 70000, 48000),
    'Setor', make_array('Educação', 'Tecnologia', 'Saúde', 'Finanças', 'Varejo')
)

# Unindo as tabelas
censo = demograficos.join('ID', renda, 'Pessoa_ID')
censo
Out[9]:
ID Idade Gênero Renda_Anual Setor
1 25 F 45000 Educação
2 32 M 62000 Tecnologia
4 28 M 55000 Saúde
5 36 F 70000 Finanças

Agora podemos analisar os dados combinados. Por exemplo, podemos calcular a renda média por gênero:

censo.group('Gênero', np.mean)
Out[10]:
Gênero ID mean Idade mean Renda_Anual mean
F 3 30.5 57500
M 3 30 58500

Ou podemos analisar a distribuição de idades por setor:

censo.group('Setor', np.mean).select('Setor', 'Idade mean')
Out[11]:
Setor Idade mean
Educação 25
Finanças 36
Saúde 28
Tecnologia 32

Conclusão

Unir tabelas por colunas é uma operação fundamental na análise de dados, permitindo combinar informações de diferentes fontes para obter insights mais completos. O método join oferece flexibilidade para diferentes tipos de junções, dependendo das necessidades da análise.

Ao trabalhar com conjuntos de dados reais, é comum que as informações estejam distribuídas em várias tabelas, e saber como combiná-las corretamente é essencial para uma análise eficaz.
