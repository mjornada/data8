Compartilhamento de Bicicletas

Nesta seção, aplicaremos os conceitos que aprendemos sobre funções e tabelas para analisar dados de um sistema de compartilhamento de bicicletas. Sistemas de compartilhamento de bicicletas se tornaram populares em muitas cidades ao redor do mundo, permitindo que as pessoas aluguem bicicletas por curtos períodos de tempo, pegando-as e devolvendo-as em vários pontos de estacionamento pela cidade.

Dados de Compartilhamento de Bicicletas

Vamos analisar dados do sistema de compartilhamento de bicicletas de uma grande cidade. Os dados contêm informações sobre viagens realizadas, incluindo duração, estações de início e fim, e informações sobre o usuário.

# Carregando os dados
bike_trips = Table.read_table(path_data + 'bike_sharing.csv')
bike_trips
Out[1]:
Trip ID Duration Start Date Start Station End Station User Type Weather
1001 12.5 2023-01-15 Downtown University Member Clear
1002 8.2 2023-01-15 Park Downtown Casual Clear
1003 15.7 2023-01-15 University Park Member Clear
1004 22.3 2023-01-16 Downtown Beach Casual Cloudy
1005 10.1 2023-01-16 Beach Downtown Member Cloudy
1006 18.5 2023-01-17 Park University Member Rainy

1008 25.2 2023-01-18 Downtown Park Casual Clear
1009 13.4 2023-01-18 University Beach Member Clear
1010 9.6 2023-01-19 Beach Park Casual Cloudy

Cada linha da tabela representa uma viagem de bicicleta. Vamos entender o que cada coluna significa:

  • Trip ID: Identificador único para cada viagem
  • Duration: Duração da viagem em minutos
  • Start Date: Data em que a viagem começou
  • Start Station: Estação onde a bicicleta foi retirada
  • End Station: Estação onde a bicicleta foi devolvida
  • User Type: Tipo de usuário (Member = assinante, Casual = usuário casual)
  • Weather: Condição climática durante a viagem

Análise da Duração das Viagens

Vamos começar analisando a duração das viagens. Primeiro, vamos calcular algumas estatísticas básicas:

# Estatísticas da duração das viagens
bike_trips.select('Duration').stats()
Out[2]:
statistic Duration
min 7.8
max 25.2
median 12.95
mean 14.33
count 10

Agora, vamos comparar a duração média das viagens por tipo de usuário:

# Duração média por tipo de usuário
bike_trips.group('User Type', np.mean).select('User Type', 'Duration mean')
Out[3]:
User Type Duration mean
Casual 16.325
Member 13

Podemos observar que os usuários casuais tendem a fazer viagens mais longas em média (16.3 minutos) do que os membros assinantes (13 minutos). Isso faz sentido, pois os membros geralmente usam as bicicletas para deslocamentos regulares, como ir ao trabalho, enquanto os usuários casuais podem estar usando as bicicletas para lazer ou turismo.

# Contagem de viagens por estação de início
bike_trips.group('Start Station')

Análise de Fluxo entre Estações

Podemos usar a classificação cruzada para analisar o fluxo de bicicletas entre as diferentes estações:

# Fluxo entre estações usando pivot
bike_trips.pivot('Start Station', 'End Station')
Out[6]:
End Station Beach Downtown Park University
Beach 0 1 1 0
Downtown 1 0 1 1
Park 0 1 0 1
University 1 1 1 0

Esta tabela mostra o número de viagens entre cada par de estações. Por exemplo, há uma viagem da estação Downtown para a estação Beach, e uma viagem da estação Beach para a estação Downtown.

Análise por Condição Climática

Vamos analisar como as condições climáticas afetam o uso do sistema de compartilhamento de bicicletas:

# Contagem de viagens por condição climática
bike_trips.group('Weather')
Out[7]:
Weather count
Clear 5
Cloudy 3
Rainy 2

Agora, vamos analisar a duração média das viagens por condição climática:

# Duração média por condição climática
bike_trips.group('Weather', np.mean).select('Weather', 'Duration mean')
Out[8]:
Weather Duration mean
Clear 15.02
Cloudy 14
Rainy 13.15

Podemos observar que as viagens tendem a ser um pouco mais longas em dias ensolarados (15.02 minutos em média) em comparação com dias nublados (14 minutos) ou chuvosos (13.15 minutos). Isso pode indicar que as pessoas estão mais dispostas a fazer viagens mais longas quando o tempo está bom.

Combinando Análises

Podemos combinar diferentes variáveis para obter insights mais detalhados. Por exemplo, vamos analisar a duração média das viagens por tipo de usuário e condição climática:

# Duração média por tipo de usuário e condição climática
bike_trips.pivot('User Type', 'Weather', values='Duration', collect=np.mean)
Out[9]:
Weather Casual Member
Clear 16.7 13.87
Cloudy 15.95 10.1
Rainy 0 13.15

Esta tabela mostra que os usuários casuais tendem a fazer viagens mais longas em dias ensolarados e nublados, mas não há registros de usuários casuais em dias chuvosos em nossos dados. Os membros assinantes, por outro lado, continuam a usar o sistema mesmo em dias chuvosos, o que sugere que eles dependem das bicicletas para seus deslocamentos diários, independentemente do clima.

Conclusão

Nesta análise, aplicamos vários conceitos que aprendemos sobre funções e tabelas para explorar dados de um sistema de compartilhamento de bicicletas. Utilizamos métodos como group, pivot e funções como np.mean para extrair insights dos dados.

Descobrimos que:

  • Usuários casuais tendem a fazer viagens mais longas do que membros assinantes
  • As estações Downtown e University são as mais populares para início de viagens
  • As viagens tendem a ser mais longas em dias ensolarados
  • Membros assinantes continuam a usar o sistema mesmo em dias chuvosos, enquanto usuários casuais parecem evitar usar o sistema nessas condições

Estes insights podem ser valiosos para os operadores do sistema de compartilhamento de bicicletas, ajudando-os a entender melhor os padrões de uso e a tomar decisões informadas sobre a alocação de recursos, manutenção e expansão do sistema.
